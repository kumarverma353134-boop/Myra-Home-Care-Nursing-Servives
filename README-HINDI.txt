MYRA DYNAMIC QR WEBSITE — UPLOAD GUIDE

Repository:
https://github.com/kumarverma353134-boop/Myra-Home-Care-Nursing-Servives

ZIP ke andar 4 files hain:
1. index.html
2. config.json
3. myra-banner.jpg (aapka diya hua banner)
4. README-HINDI.txt

UPLOAD:
1. GitHub repository kholo.
2. Add file > Upload files.
3. ZIP ko pehle phone/computer par extract karo.
4. Extract hui chaaron files ko repository ke root mein upload karo.
5. Commit changes.

PAGES:
Repository > Settings > Pages
Source: Deploy from a branch
Branch: main
Folder: /(root)
Save.
Deploy hone ke baad Visit site par click karo.

Aapke repository ke exact naam mein "Servives" spelling hai, isliye expected URL:
https://kumarverma353134-boop.github.io/Myra-Home-Care-Nursing-Servives/
Agar GitHub Pages URL alag dikhaye, Settings > Pages mein diya hua Visit site URL use karein.

QR:
Final website URL ka QR banayein. APK update karne par QR dobara banane ki zarurat nahi.

APK PUBLISH:
GitHub Releases mein APK upload karein. Phir config.json mein available=true, version, updated aur apkUrl update karein.
APK hide karne ke liye available=false set karein.
Static page par button hide hoga; pehle share kiya direct APK link tab tak chal sakta hai jab tak release asset delete/unpublish na ho.

NOTE:
Website aur repository public honge. Sirf authorised APK upload karein. MYRA services ki availability, staff qualification, clinical order, quotation aur booking manager se confirm honi chahiye. Emergency mein local emergency service/nearest hospital se sampark karein.
